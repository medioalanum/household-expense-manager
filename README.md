# Household Expense Manager

A simple Python application for recording household expenses, generating monthly reports, and identifying the ten highest transactions.

This project was developed as part of the ProfessionAI Data Engineering course.

## Features

- Add expenses with date, description, and amount
- Persist transactions in a CSV file
- Group totals by year and month
- Display the ten highest expenses
- Validate dates, descriptions, and positive monetary values

## Usage

The project is available as a Google Colab notebook. Open the notebook, run the setup cell, then run the menu cell. Choose `0` to exit.

> The Colab notebook is the course delivery format. The GitHub copy provides version control and portfolio documentation.

## Data privacy

`expenses.csv` is intentionally ignored by Git because it may contain personal financial information. Use `expenses_example.csv` for demonstrations.
